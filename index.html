Ovidian Agents is operated by Adrien Funel for his own use. It coordinates AI assistants through a private messaging interface, including a Japanese-learning assistant. It is not offered as a public service.

Google Drive integration

When requested, the assistant saves a new text or Markdown document in a dedicated Google Drive output folder and returns its link. The current agent tool creates files; it does not offer deletion, sharing changes or browsing of the entire Drive.

The integration requests Google’s drive.file scope, which limits access to files created by or specifically made available to the application. This Drive connection does not request Gmail, Calendar or full-Drive access.

Google sign-in is performed through a desktop authorization flow. This website is an information page, not a sign-in portal or access point to the private assistants.

Gmail administrator integration — pilot

The administrator helps review personal correspondence and identify suggested next actions. Read-only Gmail access is used to discover recent received and sent messages, including archived mail. Manual labels are not required. Initial discovery covers a recent 30-day window; subsequent collection records mailbox changes. Spam, Trash and Drafts are excluded from message-body review.

The reader upgrade supports bounded conversation context, text extracted from HTML email, and locally saved review summaries. Attachments are not downloaded by the reader. Scheduled monitoring and a full action-management workflow are still being developed; current collection and review are operator-triggered.

Saving a Gmail draft remains planned only after Adrien approves its exact recipients, subject and body. Sending remains a manual action in Gmail. Google’s draft-management permission also permits sending, so separate credential isolation and approval controls must be implemented and tested before draft creation is enabled.
