Ovidian Agents

A personal workspace for learning, research and everyday assistance.

Ovidian Agents is operated by Adrien Funel for his own use. It coordinates AI assistants through a private messaging interface, including a Japanese-learning assistant. It is not offered as a public service.

Google Drive integration

When requested, the assistant saves a new text or Markdown document in a dedicated Google Drive output folder and returns its link. The current agent tool creates files; it does not offer deletion, sharing changes or browsing of the entire Drive.

The integration requests Google’s drive.file scope, which limits access to files created by or specifically made available to the application. It does not request Gmail, Calendar or full-Drive access.

Google sign-in is performed through a desktop authorization flow. This website is an information page, not a sign-in portal or access point to the private assistants.
