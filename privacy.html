Privacy policy

Last updated: 5 October 2026

Ovidian Agents is a personal AI assistant platform operated by Adrien Funel. This policy describes its current Google Drive integration, Gmail integration under development, and related processing. It is not a public service accepting user registrations.

Information accessed and used

The Google integration requests https://www.googleapis.com/auth/drive.file. This permits access to files created by or explicitly made available to the app, rather than general access to all Drive files.

The current agent tool receives a requested filename and text, creates a document in a dedicated output folder, and returns the file identifier and link. File metadata may also be accessed during setup and troubleshooting. OAuth credentials are used to authorize these operations. The Drive connection does not request Gmail or Calendar access.

Gmail integration under development

Initial Gmail setup requests https://www.googleapis.com/auth/gmail.readonly, which permits reading email messages and settings across the authorized mailbox. The planned assistant will process selected messages carrying the Ovidian/Admin label, including message identifiers, senders, recipients, subjects and text bodies, to summarize correspondence and propose replies. The label restriction must be enforced by the application; it does not narrow Google's OAuth permission. Initial agent functionality will not download attachments.

A later stage is intended to request https://www.googleapis.com/auth/gmail.compose for user-approved drafts. This scope permits both draft management and sending. Ovidian's intended workflow permits saving a draft only after Adrien approves its exact recipients, subject and body, and leaves sending to Adrien manually in Gmail. Credential isolation, approval checks and the exclusion of send operations must be implemented and tested before enabling that stage. These controls are not yet deployed.

Selected email content and proposed replies used in assistant interactions may be processed by Anthropic, stored on the DigitalOcean server, and shown through Telegram. Copies may remain in conversation records, operational records and encrypted backups under the retention practices below. Gmail messages and saved drafts remain in the Google account until the account owner removes them. Setup credentials are initially held on the operator's computer; server integration is a later step. Gmail authorization is separate from the existing Drive credential files.

Storage and security

Generated documents are stored in the authorized Google Drive account. OAuth credentials are held on the privately administered server with restricted filesystem permissions and included in encrypted recovery backups. A temporary upload file is created on the server and normally removed after the operation; interrupted operations may require cleanup.

Assistant conversations, tool results and operational logs may be retained on the server and in backups. The messaging interface also retains information according to its provider’s settings and policies. Credentials are not intended to be included in model prompts, public source repositories or this website.

Service providers and disclosures

Google processes authorization requests and stores Drive documents. The platform uses a hosted server and AI and messaging providers, currently including DigitalOcean, Anthropic and Telegram. Information included in assistant requests, generated text, and returned file links may be processed by the providers involved in that interaction. Their own policies also apply.

GitHub Pages hosts these public information pages, and Cloudflare provides domain and DNS services. Hosting providers may process technical request information such as IP addresses. These pages contain no application analytics scripts, advertising or sign-in forms.

Ovidian does not sell Google user data or use it for advertising. The operator does not use Google API data to train generalized AI models. Google API data is used to provide the requested personal-assistant functionality, subject to the Google API Services User Data Policy, including its Limited Use requirements. This statement does not replace the separate policies and contractual terms of service providers.

Retention and deletion

Drive documents remain until deleted by the account owner. Conversations and operational records are retained until removed under the platform’s settings or by the operator; no single automatic deletion period currently applies to all records.

Automatic encrypted recovery backups are configured to move to Drive Trash after 30 days, following a successful backup. Trashed copies can persist until Google’s trash deletion completes. Separately retained manual backups may remain longer.

Deleting an active file or credential does not immediately remove historical copies from existing backups. To request deletion or ask about retained information, contact the operator.

Revoking access

Access can be revoked through Google Account third-party connections by selecting Ovidian Agents and removing its access. Revocation stops future authorized API use; it does not itself delete existing Drive documents, Gmail messages or drafts, conversations or backups. Those can be removed separately.

Changes and contact
